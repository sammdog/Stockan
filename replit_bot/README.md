# Stockan на Replit

Замените содержимое корневого `main.py` в Replit файлом [main.py](main.py). Оставьте текущие `requirements.txt` и `.replit`. Используйте прежний файл Google Drive и действующие секреты:

- `TELEGRAM_TOKEN` — токен бота.
- `GOOGLE_DRIVE_FILE_ID` — ID файла результатов Stockan.
- `YOUR_CHAT_ID` — Telegram ID владельца. Если секрет не задан, доступен обычный список рекомендаций.

После слияния модели в `main` GitHub Actions опубликует отчёт при следующем штатном запуске. Бот умеет показывать прежний отчёт во время перехода.

- `/results` показывает рекомендации с названиями, шагом торгового плана, ценой за акцию и размером лота.
- `/capital 7500` рассчитывает заявки на свободный остаток 7 500 ₽ в личном чате владельца. Сумма нужна для одного расчёта и не сохраняется. Указывайте деньги, свободные с учётом уже выставленных заявок.
- На тикер выделяется до 1 000 ₽ номинала, покупаются только целые лоты. Из общего бюджета резервируется 0,05% на комиссию покупки. В строке заявки лимит указывается за одну акцию.
- После исполнения покупки вручную выставьте лимит продажи на 3% выше фактической цены исполнения с учётом шага цены у брокера.

Торговый список использует завершённые дневные свечи. Если свечи акций свежее остальных входных данных, бот показывает причину паузы.
