# Проверка прогнозов Stockan

Модель оценивает максимальное изменение **цены закрытия** за следующие 14 строк после объединения источников. Эти строки могут пропускать торговые сессии. Лимитная продажа зависит от внутридневной цены, а покупка должна исполниться до продажи. Для этих задач нужны разные метрики.

## Архив прогнозов

После каждого успешного анализа Actions сохраняет `latest_results.json` в артефакт `stockan-forecast`. В публичном репозитории такие артефакты доступны пользователям GitHub с доступом на чтение с учётом правил GitHub. Артефакты нужно скачивать до истечения срока хранения. Файл содержит прогнозы, дату и цену исходной свечи для каждого тикера, время формирования JSON и текущие метрики. Старые поля сохраняются для совместимости с Telegram-ботом.

Распакуйте архивы в отдельные подпапки `snapshots/`. Для свечей нужен CSV MOEX одного согласованного режима торгов с колонками `ticker,date,low,high,close`. Даты задаются в формате `YYYY-MM-DD`. Используйте цены в рублях в той же шкале, что и прогноз, одну свечу на тикер и дату. Периоды сплитов, приостановок торговли и пробелов в выгрузке нужно проверить перед интерпретацией результатов.

```sh
python tools/backtest_orders.py --snapshots snapshots --candles candles.csv \
  --trades trades.csv --fee-bps 5 --entry-sessions 1 --hold-sessions 10
```

Пять базисных пунктов в примере означают комиссию 0,05% на каждую сторону. Укажите фактическую комиссию.

Скрипт выбирает последний доступный снимок каждого московского дня и использует тикеры из обеих групп потенциала. Заявка действует с первой доступной свечи после дня сигнала. Лимит покупки на 0,5% ниже исходного закрытия, лимит продажи на 3% выше цены входа. Вход учитывается по лимиту при касании дневным минимумом. Выход по цели возможен с первой свечи после входа. При истечении срока позиция оценивается по закрытию последней свечи окна. Сроки измеряются свечами тикера.

CSV показывает исход каждой заявки. Незавершённые и пропущенные случаи учитываются отдельно. Доля достижения цели считается среди закрытых сделок, а средняя доходность учитывает комиссии на обе стороны. Для оценки потерь полезно просмотреть выходы по сроку на стрессовых датах и сравнить результаты для 5, 10 и 14 сессий.

Касание дневного максимума или минимума приближает исполнение. Данных об очереди заявок, спреде, проскальзывании и движении цены внутри свечи здесь нет. Сделки моделируются независимо, включая пересечения по одному тикеру. Для оценки портфеля нужны ограничения на капитал и размер позиции, правила повторного входа и учёт открытых позиций. Принудительный выход по сроку — сценарий теста для измерения убытка, который отличается от удержания просевших бумаг.

## Проверка модели по времени

Текущая CV использует обычные блоки KFold. Строки после тестового периода могут попасть в обучение, а целевые окна у соседних строк пересекаются. Синтетические индексы обучаются на всей истории. Поэтому текущий MAE в процентных пунктах — диагностическое число, а формула `100 - MAE` не даёт процент удачных сделок.

Для исторической оценки воспроизводите на каждую дату только данные, доступные на тот момент. В каждом проходе обучайте и синтетические индексы, и модели акций на прошлом. Включайте в обучение только цели, горизонт которых уже завершён к границе теста. Подбор гиперпараметров выполняйте во внутренних временных блоках. Проверяйте доступность капитализаций на дату сигнала при всех сравнениях.

Сравните действующую модель с простыми базовыми вариантами на одних датах, тикерах и торговых правилах. Для текущей цели базой может служить медиана роста за предыдущие завершённые окна. Для заявок — те же лимиты на всех доступных бумагах из того же списка без отбора по прогнозу. Измерьте MAE, среднее завышение прогноза и результаты по диапазонам прогнозируемого роста. Последний период и стрессовые окна проверяйте после фиксации правил.

- [Временные разбиения scikit-learn](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)
- [Скользящее начало прогноза в Forecasting: Principles and Practice](https://otexts.com/fpp3/tscv.html)
- [Данные MOEX ISS](https://www.moex.com/a8531)

## Сравнение вариантов по кварталам

В ветке исследования запустите `Daily Stock Analysis` с параметром `walk_forward=true`. Этот режим строит датасет и сохраняет CSV с тремя прогнозами и фактической целью в артефакт `stockan-walk-forward`. Сводки `WALK_FORWARD` доступны в логе. Запись в Google Drive в этом режиме пропускается.

В каждом квартале с октября 2025 года модели обучаются один раз на его начало. Для обучения берутся только цели, все 14 будущих наблюдений которых уже прошли. Синтетические индексы переобучаются на данных до границы квартала, после чего восстанавливаются их значения и лаги. Из теста исключается цель, если в её окно попадает последняя доступная свеча. Отдельная сводка охватывает март–май 2026 года. Для этого режима курс USD загружается из [официального архива ЦБ](https://www.cbr.ru/development/SXML/) по дате вступления в силу. На дни без нового курса переносится последний действующий курс. Это закрывает дыры в рабочем кэше, которые видны при объединении рядов по дате.

Сравниваются медиана цели по завершённым обучающим окнам и две модели LightGBM с одинаковыми фиксированными параметрами. У одной веса одинаковы, у другой примеры с целевым ростом выше 12% удваиваются. Сохранённые параметры отдельных бумаг могли подбираться уже после тестовых дат, поэтому для сравнения они не загружаются.

MAE и среднее завышение выражены в процентных пунктах. Метрика топ-10 показывает, как часто следующая цена закрытия в пределах цели достигала заданного порога для бумаг с наибольшим прогнозом в тот же день. Исполнение заявки оценивается отдельным тестом лимитных ордеров. Текущий перечень бумаг и исторические капитализации используются ретроспективно. Для полноценной симуляции также нужны состав вселенной и исходные данные зафиксированные на каждую дату, включая время доступности дневных цен.

### Разбор параметров, функции потерь и признаков

Режим исследования в ветке `research/model-variants` использует восстановленный рабочий ряд USD. На тех же квартальных границах и строках сравниваются семь вариантов:

| Вариант | Отличие |
|---|---|
| median | Медиана завершённых целевых окон по тикеру |
| equal_weight | LightGBM по тикеру, обычная квадратичная потеря |
| double_tail_weight | Та же модель, двойной вес целей выше 12% |
| l1 | Модель с равными весами и абсолютной потерей |
| compact_l1 | Абсолютная потеря, до семи листьев, глубина до трёх, минимум 60 строк в листе, более медленное обучение |
| relative_l1 | Компактная модель, процентные изменения вместо уровней и отношение объёма к средней |
| pooled_relative_l1 | Общая компактная модель с относительными признаками, тикером как категорией и минимум 300 строк в листе |

Контраст между `l1` и `compact_l1` проверяет пакет настроек регуляризации. Контраст между `compact_l1` и `relative_l1` проверяет сокращённый набор относительных признаков. Контраст с объединённой моделью также меняет минимальный размер листа, поэтому не изолирует только эффект объединения.

Помимо полной выборки и весеннего периода выводятся метрики для случаев, когда закрытие снизилось на 15% или более за предыдущие 28 наблюдений. Состав этой подвыборки определяется только ценами к моменту сигнала. Кварталы уже использовались для исследования, поэтому следующие данные нужны для проспективного подтверждения.

[Повторный прогон с восстановленным USD](https://github.com/sammdog/Stockan/actions/runs/45645294407) использовал 27 335 прогнозов на тех же 274 датах. Метрики совпали с предыдущим прогоном для первых трёх вариантов.

| Метод | MAE, п.п. | Средняя ошибка, п.п. | Топ-10: достигли +3% | MAE после падения, п.п. |
|---|---:|---:|---:|---:|
| Медиана | 4,463 | −1,734 | 55,44% | 8,378 |
| LightGBM L2 с равными весами | 6,742 | +2,649 | 48,83% | 10,585 |
| LightGBM L2 с двойными весами | 6,763 | +2,519 | 48,58% | 10,756 |
| LightGBM L1 | 5,830 | +1,440 | 48,32% | 9,460 |
| Компактный LightGBM L1 | 5,149 | +0,128 | 50,18% | 8,949 |
| Относительные признаки по каждой бумаге | 4,618 | −1,339 | 55,44% | 8,301 |
| Общая модель с относительными признаками | 4,470 | −1,497 | 55,18% | 8,039 |

В срезе после падения 3 904 примера. L2 с двойными весами дал 269 прогнозов от +20%, из которых 10 достигли порога. Общая модель не дала таких прогнозов, хотя фактически порог достигнут в 535 примерах. Она подходит как кандидат на тест рейтинга, но предсказывает редкие отскоки консервативно. В марте–мае доля достижения +3% в её топ-10 составила 41,33% против 37,50% у медианы. На полной выборке она почти совпала с медианой по MAE и доле достижения +3%.

## Портфельный тест лимитных заявок

В исследовательской ветке `research/portfolio-backtest` режим `walk_forward=true` добавляет сравнение портфелей для исторической медианы и трёх вариантов LightGBM. Артефакт `stockan-walk-forward` содержит прогнозы, итоговую сводку, дневную стоимость портфеля и журнал исполнений.

В конце каждой второй рыночной сессии выбирается топ-10 по сигналу. Исходная цена — закрытие этой сессии. В порядке рейтинга на каждую заявку резервируется 1 000 ₽ плюс комиссия. Покупка может исполниться только в следующую общую сессию по 99,5% исходной цены, если дневной минимум достиг лимита. Заявки без касания отменяются. Повторные покупки одного тикера учитываются отдельными позициями.

Лимит продажи — 103% цены покупки. Исполнение проверяется по дневному максимуму со следующей сессии после покупки, поскольку дневная свеча не показывает порядок касаний. Продажа действует вплоть до конца истории, в том числе после 14 календарных дней. В расчёт входят комиссии обеих сторон. Продажам при касании присваивается цена лимита, а открытые позиции оцениваются по последнему доступному закрытию за вычетом комиссии условной продажи.

Основная метрика — конечная стоимость портфеля минус стартовый капитал. Она равна сумме реализованной прибыли и результата открытых позиций. Приводятся также максимальная просадка, число позиций, стоимость их входа и изменение стоимости портфеля за каждый календарный месяц. Последний месяц включает наблюдение за ранее купленными позициями после окончания доступных сигналов.

Базовый сценарий использует 50 000 ₽ и комиссию 0,05% за сторону. Для чувствительности сравниваются 100 000 ₽, повышенная комиссия 0,20% и сдвиг выбора сигналов на одну рыночную сессию. Дробные количества разрешены. Дневные OHLC дают проверку касания лимита. Исполнение в очереди, биржевой шаг цены, налоги, дивиденды и корректировка корпоративных действий в этой симуляции не моделируются.

## Сравнение правил ручной торговли

Код в `tools/trading_rules.py` расширяет портфельный тест без изменения модели. При каждом сравнении стартовый капитал 50 000 ₽, комиссия 0,05% за сторону, заявки раз в две сессии и возможность купить до десяти бумаг. Акции на закрытии ранжируются по исходному прогнозу или по оценке среднего результата заявки. Сумма по умолчанию 1 000 ₽ на позицию. Базовый сценарий повторяет предыдущий тест.

| Группа | Что меняется относительно бенчмарка |
|---|---|
| Пауза | После закрытия на 8% ниже цены входа новые покупки тикера откладываются на 10, 20 или 30 сессий. Старая позиция сама по себе не продлевает паузу. |
| Бюджет | Новые заявки ограничены долей 50% или 70% портфеля в акциях. |
| Средний результат | Пороги 0%, 0,25%, 0,5% и 1% среднего результата заявки. Также отдельный рейтинг по среднему результату и проверка минимум трёх бумаг выше порога. |
| Вход | Фиксированный дисконт 0,25%, 1%, 1,5% или выбор по истории тикера. |
| Тейк | Фиксированные +2%, +4%, +5%, выбор по истории тикера или пересмотр открытой заявки каждые 10 сессий. |
| Выход по времени | Продажа на открытии после 15, 30 или 60 сессий удержания. |
| Выход по риску | Продажа на следующем доступном открытии после убытка на закрытии в 5%, 8% или 12%. Ещё один сценарий требует не менее 10 сессий удержания, убытка по бумаге 5% и падения IMOEX на 5% за 20 его наблюдений. |
| Рынок | Вдвое меньшие заявки при отрицательном 20- или 50-дневном изменении IMOEX, пропуск при отрицательном 20-дневном изменении или падении на 5%. Постоянное уменьшение вдвое служит простым контролем размера. |

Средний результат заявки оценивается в начале каждого месяца на предыдущих 240 доступных датах сигнала. Учитываются только исходы, полностью завершившиеся к началу месяца. Сравниваются лимиты входа и тейка из заданной сетки. Неисполненная заявка даёт ноль; при исполнении считается результат продажи по тейку или условной продажи в конце 20-сессионного окна. Средняя тикера сглаживается средней по бумагам с весом 30 наблюдений. Это оценка для рейтинга и назначения лимита, поэтому она не заставляет портфель закрывать реальную позицию через 20 сессий, если отдельным правилом не задан выход по сроку.

Каждое правило испытывается отдельно с четырьмя рейтингами. Для комбинаций сначала для каждой группы выбирается вариант с лучшим итогом до 1 июня 2026 года. Затем правила добавляются в порядке изолированного выигрыша, если улучшают результат раннего периода в комбинации. Поздняя проверка стартует с чистого портфеля и фиксированными настройками; дополнительно сдвигается расписание запуска на одну сессию. Параллельно считается непрерывный сценарий с октября 2025 года без сброса позиций в июне. Данные относятся к уже исследованной истории, поэтому поздний отрезок отделён от выбора правил внутри этого теста и потребуется отдельное подтверждение на будущих датах.
